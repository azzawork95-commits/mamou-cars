IMPORTANT
Le QR Code est préparé pour l'URL GitHub Pages prévue, mais ne sera actif qu'après :
1. Créer un dépôt public nommé "mamou-cars" dans GitHub.
2. Envoyer le fichier index.html à la racine du dépôt.
3. Ouvrir Settings → Pages.
4. Dans Build and deployment, choisir Deploy from a branch.
5. Choisir Branch: main et Folder: / (root), puis Save.
6. Attendre la publication à https://azzawork95-commits.github.io/mamou-cars/.
